# B056 – Trace engine v2: line art for cel-shaded and anime art

Model: **Opus**, in three stages — one agent per stage: **7a** line mask + centerlines + width → `brush()` strokes (tested on `wikipe-tan-full-length-bw.png` and synthetic strokes); **7b** fills grown under the lines + sub-pixel outlines; **7c** two-scale corners, Bézier fitting, primitive snapping, hair flow and spikes, scored on the cel references. Each stage lands before the next starts. Design: `docs/Linkz – Tracing v2.md` (the pipeline, options, code shape, tests). References to tune on: `docs/Art/References/trace/` (see ATTRIBUTION.md; `wikipe-tan-casual.png` is the main one; `full-length-bw` for pure lines; `sorceress` is the painted stretch case). Repo: `linkz`, lane `lib/trace/` (lizard). Rules: `docs/Batches/_v11-rules.md` (all lizard; per-pixel speed problems go to lizard-script as needs with numbers, not workarounds).

Build the `"lineart"` mode of `trace` as Tracing v2 describes (line mask, orientation field, centerlines with width → `brush()` strokes with pressures, stroke building through junctions along the flow, spiky vs blunt tips, fills grown under the lines with shared edges, sub-pixel outlines, two-scale corners, Bézier fitting, primitive snapping, layered code with a named palette). `linkz trace --mode lineart in.png out.lzdraw` and the MCP `trace` tool accept it; the existing photo mode stays as it is.

Measure on the references: time per image at 512/1024 px, number of strokes/fills/primitives, and the render difference (render the traced code with `linkz render`/paint and compare with the original: mean color error, line-mask overlap), before/after each improvement. Synthetic tests for circle, rotated rect, tapered stroke, Y junction, crossing strands, a 3-spike tuft, fills behind an outline. Report the table and side-by-side renders in `docs/Art/Checks/trace/`. The trace dialog UI (R003-6) is a later Sonnet batch.
